Press `?` in the app to see this list. `⌘` is `Ctrl` on Windows and Linux.

## General

| Keys | Action |
|---|---|
| `?` | Keyboard shortcuts |
| `⌘K`, `⌘F` | Search the board |
| `⌘P`, `⌘⇧P` | Commands |
| `⌘Enter` | Select all search results |

## Tools

| Keys | Action |
|---|---|
| `V` | Select |
| `H` | Hand |
| `F` | Frame |
| `N` | Sticky note |
| `T` | Text |
| `R` | Timer |
| `C` | Jira card |
| `M` | Modules |
| `Esc` | Back to Select |

## Edit

| Keys | Action |
|---|---|
| `⌘Z` | Undo |
| `⌘⇧Z`, `Ctrl+Y` | Redo |
| `⌘C` | Copy |
| `⌘V` | Paste at the cursor |
| `⌘D` | Duplicate |
| `⌘A` | Select all |
| `Delete`, `Backspace` | Delete selection |
| `Shift` + click | Add to selection |

## Canvas

| Keys | Action |
|---|---|
| `Space` + drag | Pan |
| `Alt` + drag | Move without snapping |
